# Benchmark source audit · 2026-10-03

## Scope and interpretation

This audit covers all 82 real Epoch benchmark datasets, excluding the model-metadata and benchmark-metadata CSV files, plus the Artificial Analysis index contract. The table below records the baseline source review, not a claim that every historical result has been rerun. A recent download does not establish a recent evaluation date.

## Direct publisher evidence

These nine collectors were exercised against their public sources. They are wired to the existing six-hour refresh workflow. Upstream version/schema changes fail closed; an unavailable feed may retain a validated, dated snapshot with a visible partial-health status while healthy feeds advance. Missing or invalid fallback evidence blocks publication.

## Data and presentation fixes

- Epoch primary columns and stored units follow the archive's benchmark metadata; sub-unit ceilings do not erase a documented percentage or fraction scale
- BTF-3 ranks lower pooled scores first
- Benchmark version, metric, unit, and source-native system identity are preserved; multiple agents or reasoning settings are separate observations
- Current publisher feeds replace their older Epoch copies in the default Stats menu. Historical evidence remains accessible in Compare, and superseded FrontierMath editions are not relabeled as v2
- Source-contract-aware selection prevents a newer legacy cache from undoing corrected data; the Compare client likewise avoids protocol downgrades
- Measured-record indexes support benchmark switching without relying only on the initially loaded models
- Publisher refresh failures retain original fetch/observation dates; failed attempts do not make old evidence look new

## Remaining source limitations

- ExploitBench's scaffold/budget/regime provenance is incomplete in the aggregate export. Do not combine CONTROL and ALL regimes or reinterpret raw capability counts as normalized accuracy
- Several fixed historical benchmarks have no maintained frontier-model leaderboard. Retain their dataset identity and original evidence rather than inventing fresh results
- Most Epoch runs lack explicit evaluation dates. Model release dates and fetch dates must not fill that field
- Artificial Analysis's API reports a major/minor index version (for example 4.3), while the methodology page can name a patch release. Do not infer the patch version from an API value or retrieval date. Coding and Agentic indexes are derived from the same evaluation set
- The production release requires the reviewed v2 publication-function migration. It preserves v1 compatibility, the 30-second timeout, service-role-only execution, and the two-slot rollback boundary. Isolated PostgreSQL tests cover promotion, rejection, rollback, and permissions; applying it to production is a separate release step
